# CaroAI

CaroAI is an AI-powered Gomoku platform.

## Project Goals

- Human vs AI
- Human vs Human
- AI move suggestion and analysis
- PostgreSQL game history
- Dockerized application
- GitHub Actions CI/CD
- Public HTTPS deployment

## Technology Stack

- Python
- FastAPI
- JavaScript
- PostgreSQL
- scikit-learn
- Docker
- GitHub Actions
- Docker Hub
- Render
